# Agentic Orchestration — Agent + Pipeline

Field-training project implementing two AI orchestration patterns using IBM watsonx.ai and watsonx Orchestrate:

- An agentic HR onboarding assistant.
- A deterministic support triage pipeline.

## Development Environment

- Python 3.11
- IBM watsonx Orchestrate ADK
- IBM watsonx.ai SDK

The detailed architecture and implementation plan will be finalized after completing the platform capability smoke tests.
